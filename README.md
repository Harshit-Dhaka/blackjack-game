# Blackjack Game 🃏

A simple and interactive Blackjack game built using vanilla JavaScript, HTML, and CSS.

## Features
- Interactive gameplay with buttons to start the game and draw new cards.
- Dynamic tracking of player chips, current hand, and card sum.
- Automated win, lose, and blackjack condition checks.

## Code Structure
- **Objects & Arrays:** Manages player data and card hands.
- **DOM Manipulation:** Dynamically updates the user interface (`message-el`, `sum-el`, `cards-el`, `player-el`).
- **Random Card Generation:** Uses `Math.random()` to simulate standard card drawing logic.
